# Além da Trilha

Uma pequena expedição 3D de jipe pela Serra do Sol. Siga a estrada de terra, descubra quatro lugares especiais e aproveite a viagem no seu ritmo.

## Como jogar

- Clique em **Começar a expedição**.
- Use **WASD** ou as setas para dirigir; **Espaço** para frear.
- No celular, use os controles na tela.
- Ative o som pelo botão no canto superior direito.

Para rodar localmente, sirva esta pasta por HTTP (por exemplo, `python3 -m http.server 3002`) e abra `http://localhost:3002`.
